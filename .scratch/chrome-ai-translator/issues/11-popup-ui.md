# 11: Popup：语言选择与翻译开关

**What to build:** 工具栏弹窗提供高频操作：选择目标语言、全局开关翻译、把当前站点快捷加入/移出排除列表。设置即时生效并持久化，再次打开浏览器仍保留。

**Blocked by:** 08

**Status:** ready-for-agent

- [x] 可从下拉框选择目标语言，切换后页面按新语言重新翻译
- [x] 可一键开关翻译，关闭后不再翻译并按设定处理已译内容
- [x] 可把当前站点快捷排除，该站此后不再自动翻译
- [x] 所有选择持久化保存，浏览器重启后仍生效
- [x] Popup 打开即显示当前生效的语言与开关状态

**实现备注：** 切换目标语言后会自动重载当前标签页——已渲染的译文属于旧语言，重载是最直接让新语言生效的方式（代价是丢失滚动位置，待 09 实时监听落地后可改为原地重译）。主机名读取依赖已有的 http/https 主机权限，未额外申请 `tabs` 权限。
