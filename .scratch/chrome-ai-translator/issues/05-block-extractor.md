# 05: 段落提取器

**What to build:** 输入一段 DOM，输出一组「段落块」——把同一块级元素内的文本聚合为一个翻译单元，并给出稳定标识。自动跳过不该翻译的区域（脚本、样式、代码、输入控件）以及已经翻译过的节点。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 遍历文本节点并聚合成块级翻译单元，每个块有稳定标识
- [x] 跳过脚本、样式、代码、文本域等不该翻译的节点
- [x] 跳过已翻译标记的节点，避免重复提取
- [x] 过短或空白的文本块被过滤，不产生无意义的翻译请求
- [x] 单元测试（DOM 环境）覆盖：聚合、跳过规则、已译跳过、空白过滤

**实现备注：** 稳定标识用 `data-ai-block-id` 写入元素并复用，保证同一元素多次提取 id 不变。跳过标记统一为 `data-ai-translated`（与渲染器共用同一常量）。
