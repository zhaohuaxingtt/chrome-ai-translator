# 12: Options：API 配置与站点排除

**What to build:** 设置页让用户配置自己的 AI 服务（接口地址、密钥、模型），管理排除站点列表，并查看/清空翻译缓存。

**Blocked by:** 08

**Status:** ready-for-agent

- [x] 可填写并保存接口地址、API 密钥、模型名，保存后在翻译中立即生效
- [x] 密钥在界面中以遮蔽方式显示，不明文暴露
- [x] 可增删排除站点，被排除的站点不自动翻译
- [x] 可查看缓存占用并可一键清空

**实现备注：** 密钥输入框为 `type="password"`（遮蔽）。「缓存占用」读的是 `navigator.storage.estimate()` 的整站用量，是近似值而非精确的译文占用——IndexedDB 没有原生的按库统计接口，精确统计需要遍历计数，对设置页而言不值得。
- [x] 配置项持久化保存，浏览器重启后仍生效
