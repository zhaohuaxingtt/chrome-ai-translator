# 02: 翻译缓存层

**What to build:** 一个不依赖浏览器的缓存模块：通过注入的存储端口同时提供内存 LRU 热缓存与持久化缓存。以「原文 + 目标语言」为键，命中即返回译文，未命中才需要调用 AI。容量满时按最近最少使用淘汰。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 缓存模块不 import 任何 chrome API，存储通过注入端口访问
- [x] 键为「目标语言 + 原文」，跨页面、跨站点的相同句子能命中（**实现偏离：** 用原文而非 hash——hash 碰撞会静默返回错误译文，极难排查）
- [x] 内存 LRU 容量上限（约 500–1000 条）内高效命中，满时正确淘汰最少使用项
- [x] 未命中内存时回落到持久化存储，持久化命中后回填内存
- [x] 提供清空缓存的能力，供后续设置页调用
- [x] 单元测试覆盖：命中、未命中、LRU 淘汰、持久化读写、清空
