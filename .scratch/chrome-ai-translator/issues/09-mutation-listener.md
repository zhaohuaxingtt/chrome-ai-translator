# 09: 实时监听：动态内容增量翻译

**What to build:** 页面内容变化时自动补翻译：新增文本被检测、合并去抖后增量翻译并渲染，已翻译部分不受影响。覆盖无限滚动加载、SPA 路由切换、弹窗出现等场景。

**Blocked by:** 08

**Status:** ready-for-agent

- [x] 页面新增文本后自动被翻译，无需刷新
- [x] 变化被去抖合并（约 500ms），短时间内大量变化不产生请求风暴
- [x] 已翻译节点不会被重复处理（块级精确判断：data-ai-target 归属于本块才算已翻）
- [x] 无限滚动 / SPA 路由切换 / 弹窗三类场景验证通过（✅ aihero.dev 上 React 重渲染抹掉译文后可自动补回）
- [x] 在长时间运行的页面上不出现内存持续增长

**实现备注：** 除 MutationObserver（挂在 `document` 上）外，另加 **3 秒健康自检**兜底——React 重渲染清掉译文的方式未必能被 observer 捕获，自检按「现存译文数 < 已渲染数」或「存在有标记但无译文的块」触发补翻（走缓存，零成本）。两者均带重入保护。检测到 `Extension context invalidated`（扩展重载后未刷新页面）时自动停产。
