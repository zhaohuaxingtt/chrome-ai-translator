# 06: 双语渲染器

**What to build:** 给定一个段落块及其译文，把原文与译文以双语对照结构渲染进页面：原文保留并弱化显示，译文正常展示，二者并排。渲染结果可被识别为「已翻译」，且可安全回退到未翻译状态。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 渲染后原文仍保留在页面中且显示为弱化（灰）样式
- [x] 译文以正常样式展示，与原文并排
- [x] 已翻译的节点带有可识别标记，供提取器跳过
- [x] 对同一节点重复渲染是幂等的，不产生嵌套或重复译文
- [x] 提供回退能力，可移除译文恢复原文
- [x] 单元测试（DOM 环境）覆盖：结构正确、原文保留、标记存在、幂等、回退

**实现备注：** 原文存档在 `data-ai-original`，重复渲染从存档取原文（否则会把上一轮译文当原文）。弱化原文用 `opacity: 0.65` 而非固定灰色，浅色/深色主题下都能看清。
