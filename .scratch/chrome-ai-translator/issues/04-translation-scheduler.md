# 04: 翻译调度器

**What to build:** 一个调度翻译请求的纯逻辑模块：相同「原文 + 目标语言」的并发请求只发一次（去重），限制同时进行的请求数（3–5 路），失败按指数退避重试，并在缓存命中时直接短路不调 API。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [x] 调度器只依赖注入的缓存与翻译客户端，不依赖 chrome API
- [x] 同一键的并发请求只产生一次真实调用，结果共享给所有等待方
- [x] 并发上限生效（3–5 路），超出排队
- [x] 缓存命中时直接返回，不产生 API 调用
- [x] 失败按指数退避重试，重试次数有上限，最终失败向上层报告
- [x] 单元测试覆盖：去重、并发上限、缓存短路、退避重试、最终失败

**实现备注：** 只有 network 错误与 http 429/5xx 会重试，4xx 与 format 错误直接失败（重试无意义）。退避为 `baseDelay × 2^n`，默认并发 4、重试 2 次。
