# 02: 常驻悬浮球与菜单

**What to build:** 页面右下角常驻一枚悬浮球，点击展开菜单弹窗（含「翻译本页」「打开设置」「隐藏悬浮球」），球本身反映当前页是否已翻译。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 悬浮球常驻右下角，不随页面滚动消失
- [x] 点击球展开/收起菜单
- [x] 菜单含「翻译本页」主操作、「打开设置」、「隐藏悬浮球」
- [x] 球有状态区分：未翻译 / 已翻译
- [x] 浅色与深色页面上都清晰可见
- [x] 样式内联 + 高 z-index，不被宿主页面 CSS 影响
- [x] 事件 `stopPropagation`，不触发页面自身逻辑
- [x] 隐藏后本次会话不再显示
- [x] 单元测试覆盖：渲染、菜单开合、状态切换、隐藏

**实现备注：** 悬浮球状态与菜单行为抽成可注入依赖的模块（注入 document 与回调），不依赖 Chrome API，可在 DOM 环境单测。
