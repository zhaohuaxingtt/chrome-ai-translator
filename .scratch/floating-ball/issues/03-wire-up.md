# 03: 菜单与翻译联动

**What to build:** 点菜单里的「翻译本页」触发当前页翻译；再点一次取消翻译、页面恢复原文。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [x] 点「翻译本页」执行整页翻译，菜单状态同步为已翻译
- [x] 再点一次回退：移除本页所有译文，页面恢复原文
- [x] 翻译中球有进行中状态（可复用现有日志/后续接入状态提示）
- [x] 回退后切换目标语言再翻译，得到新语言译文
- [x] 联动逻辑可测（注入翻译与回退回调）

**实现备注：** 取消翻译需要记录本页已渲染的块，逐块调用 `revertTranslation`。
